Reusable animated counters with an English admin editor, shortcodes and optional WPBakery integration.

== Description ==
Create multiple counters, set numbers and suffixes, and configure independent text/number sizes for desktop, tablet and mobile. Works without Woodmart or WPBakery. Includes ring fill, arc with marker and gradient arc with marker, with centered content and configurable duration.

== Installation ==
Upload the release ZIP under Plugins > Add New > Upload Plugin, then activate WP Animated Counter. Create and publish a counter under Animated Counter, then paste its shortcode into a page.

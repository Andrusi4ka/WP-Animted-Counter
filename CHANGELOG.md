# Changelog

## 1.8.0 — 2026-10-19

First public release of the theme-independent plugin.

- Reusable counter records, English admin UI and blue accents.
- Shortcodes and optional WPBakery saved/inline elements.
- Start/final values, arbitrary suffixes, independent number and label sizes/weights.
- Desktop/tablet/mobile typography and spacing with inheritance.
- Visual alignment controls with bundled illustrations.
- Shared color scheme, custom color, background, spacing and radius.
- Viewport-triggered counting, reduced-motion support and screen-reader final values.
- Legacy preset conversion without changing previously configured pixel sizes.
- Animation placeholders, ready for future effects.
- Shared validation for admin saves and shortcodes, decimal-safe counts, balanced markup.
- Removed duplicate/obsolete CSS and unreachable editor branches.
- PHP, DOM, animation, asset, dead-code and duplication checks; WordPress integration test.

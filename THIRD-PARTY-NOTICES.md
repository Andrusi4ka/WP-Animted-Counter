# Third-party material

`assets/images/counter-icon.svg` bundles the WordPress Dashicons `performance` symbol from the installed WordPress SVG sprite for the WPBakery element icon (GPL-2.0-or-later). Device controls use WordPress Dashicons font files supplied by WordPress, which are not bundled here.

Woodmart layout illustrations were removed with the obsolete alignment UI. Woodmart, Swiper and WP Swiper are not bundled or required.

jsdom, PostCSS, jscpd, playwright-core and pngjs are development-only dependencies. Their versions/dependency metadata are recorded in `package-lock.json`; their licenses are included with their npm packages. These packages, tests and browser screenshots are excluded from release ZIPs.
